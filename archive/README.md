# Archive

Older material kept for the record. **Nothing in this folder is part of the current paper.**

| File | What it is | Why it's here |
|---|---|---|
| `SynechismCore_v23_whitepaper.pdf` | The v23 white paper | Superseded. Its coherence claim (19,940 steps, 15.8×) used a coherence metric later found to be flawed, and its scope is wider than the current paper. |
| `kaggle_exploratory_results.txt` | Early results from free-tier Kaggle runs (formerly `CONFIRMED_RESULTS.txt`) | Exploratory, mostly single runs, not re-verified. The coherence and φ results are withdrawn. |
| `old_run_plan.md` | The earlier GPU guide and four-phase run plan (Lambda Labs, H100, 10-seed full suite) | Superseded by the current paper scope (see `PAPER_SCOPE.md`) and the GPU guide in the main README. |
| `diagnostics/` | Scratch scripts and output from the September 2026 VPT-metric fix | One-off checks, not used by the current code. |

The current paper's question, results and run instructions are in the main [README](../README.md).
